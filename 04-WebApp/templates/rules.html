System Rules & Architecture

Multimodal Emotion Recognition powered by FER-2013 & DREAMER datasets

FER-2013 Facial Emotion Classifier

Facial Emotion Recognition is achieved using a mini-Xception Convolutional Neural Network trained on the FER-2013 dataset. The pipeline detects face bounding boxes using Haar Cascade Classifiers, crops and resizes face regions to 48x48 grayscale inputs, normalizes pixel values, and yields confidence probabilities across 7 emotion categories.

Angry Disgust Fear Happy Sad Surprise Neutral

DREAMER EEG Signals Integration

The system incorporates features derived from the DREAMER dataset, an electroencephalogram (EEG) dataset captured during emotion elicitation audio-visual stimuli. Valence, Arousal, and Dominance (VAD) dimension models map physiological EEG signal frequencies (Theta, Alpha, Beta) to affective states.

Input -> OpenCV Face Detection -> Alignment & Crop (48x48) -> SeparableConv2D Deep CNN -> Softmax Classification Output

System Usage Guidelines

1. Ensure proper lighting and clear face alignment when using the Live Camera recorder.
2. Uploaded video files must be in standard web formats (.mp4, .avi, .mov, .webm).
3. All user recordings and emotion statistics are stored securely in local SQLite database tables (`users.db`).
